# Street Yun — pictures for the fast 3D route

One picture per asset, made in the same image tool as the character sheets. Matterhorn turns each into a 3D model with
**Add a picture → Make 3D model (Standard, about 20 minutes)**, or many at once overnight. "Decent enough" is the goal:
the props sit behind the characters, so they only need to read clearly from the game camera.

## How every picture should look (paste this before each prompt)

> Single object only, centred, 3/4 view from slightly above, whole object visible with a little space around it, plain
> light-grey seamless background, soft studio light, no text, no people, no other objects, no ground clutter. Style:
> chunky, rounded, soft clay-like 3D toy style matching the Street Yun chibi characters (Northern Step Studio), bright
> but not neon Caribbean colours, smooth simple shapes, small details kept bold. Dominican Republic street setting.

Name each file after the asset (for example `vehicle-taxi.png`) so it lands in the right place.
