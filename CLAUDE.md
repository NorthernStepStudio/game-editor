# Matterhorn agent instructions

Before doing any work in this repository:

1. Read `AGENTS.md`.
2. Read `.agents/STARTUP.md`.
3. Run `npm run agent:start`.
4. Obey the branch/CI warning before editing, committing, pushing, opening a PR, or rerunning CI.

Do not use `feat/**` for iterative autonomous commits. Use `integration/**` until the batch is ready for intentional CI validation.

The canonical instructions remain in `AGENTS.md` and `.agents/STARTUP.md`.
